# Quick Start Guide - Virtual Drum System

## 🚀 Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
cd virtual_drum_system
pip install -r requirements.txt
```

### Step 2: Test Your System
```bash
python test_system.py
```

### Step 3: Run the Application
```bash
python main.py
```

## 🎵 How to Use

### Voice Commands (Say these clearly):
- **"Select Tamil Nadu style"** - Switch to Tamil drums
- **"Select Karnataka style"** - Switch to Karnataka drums  
- **"Select Kerala style"** - Switch to Kerala drums
- **"Select Punjab style"** - Switch to Punjab drums
- **"Start recording"** - Begin recording your performance
- **"Stop recording"** - Save your performance to playlist
- **"Play playlist"** - Play saved recordings
- **"Next track"** - Play next recording
- **"Help"** - Hear all available commands
- **"Exit"** - Close the application

### Hand Gestures (Show to camera):
- **👆 Point with index finger** → Basic drum hit
- **✌️ Peace sign (two fingers)** → Cymbal sound
- **🖐️ Open palm** → Heavy drum sound
- **✊ Closed fist** → Bass drum sound

## 🎯 Tips for Best Experience

1. **Good Lighting:** Ensure your hands are well-lit for the camera
2. **Clear Speech:** Speak commands clearly and wait for confirmation
3. **Hand Position:** Keep hands within camera frame
4. **Audio Setup:** Use headphones to avoid feedback during recording

## 🔧 Troubleshooting

**Camera not working?**
- Check if other apps are using the camera
- Try running as administrator

**Voice commands not recognized?**
- Check microphone permissions
- Speak louder and clearer
- Reduce background noise

**No sound?**
- Check speaker/headphone connections
- Verify audio drivers are installed

## 📁 Project Files Created
